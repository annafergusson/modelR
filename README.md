# modelR
Quick prototype of coding in R in CODAP, using {webr}.

The R function to use to send a data frame to CODAP is `update_table()` - first argument is the name of the table, second argument is the data frame. 

You can try it out here: https://codap.concord.org/releases/latest/static/dg/en/cert/index.html?di=https://annafergusson.online/modelR

An earlier version based on hacking a {learnr} shiny app is available here: https://github.com/annafergusson/BYOC_CODAP

Let's collaborate if you are interested in developing this further!
